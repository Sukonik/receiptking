# ReceiptKing Jungle Brand Pack

The Clerk logo and six jungle app icons. The logo assets use the approved full-body tamarin with raised receipt. The Jungle icons use the same pose as a glossy forest-green emblem against distinct realistic botanical backdrops.

## Logos

- `assets/brand/logos/receiptking-clerk-black.webp` — black mark, transparent
- `assets/brand/logos/receiptking-clerk-greyscale.webp` — greyscale mark, transparent
- `assets/brand/logos/receiptking-clerk-forest-green.webp` — default green mark, transparent
- `assets/brand/logos/receiptking-clerk-lime-green.webp` — lime concept mark, transparent

## Jungle icons

HackBerry (default), Sapote, GroundCherry, Fig, TreeGrape, IceCreamBean. The source pack contains the original masters and WYWO-style export sizes. The repository carries optimized WebP interface previews plus the browser and touch assets needed by the live menu. These are raster CGI app icons. The full-body mascot intentionally remains present at every size.

ReceiptKing defaults to `assets/brand/icons/hackberry/`. The manifest uses the 192-pixel PNG and optimized 512-pixel WebP. The menu updates the 32-pixel browser favicon and Apple touch icon. Alternate icon folders can be selected independently of the UI theme.

## Themes

`JUNGLE-THEMES.md` has the full color mapping and implementation notes. ReceiptKing v1.2 installs the eight themes with light, dark, and system-auto modes alongside the six selectable Jungle app icons.
